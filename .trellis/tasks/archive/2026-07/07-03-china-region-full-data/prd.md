# 升级全国完整行政区划数据

## Goal

把 CitySelect 当前 MVP 小样本数据升级为可维护的全国行政区划数据集，
支撑全国范围的城市 / 区县 / 乡镇街道选择、搜索和校验。

用户已明确需要“全国完整城市库”。第一版覆盖中国大陆省 / 市 / 区县 /
乡镇街道四级，包含港澳台数据；港澳台允许使用可变深度路径和地区专属
层级名称；不纳入村 / 社区 / 居委会第五级。

## Confirmed Facts

- 当前 `packages/data` 只内置 MVP 小样本：
  - `内置城市列表`：12 个城市。
  - `内置行政区列表`：26 条省市区样例。
  - 数据版本：`2026.07-cn-region-mvp`。
- 当前 root 命令已有 `validate:data`，会先 `tsc -b` 再运行
  `packages/data/dist/validate-data.js`。
- 当前校验覆盖唯一编码、名称、级别、父级、拼音、首字母和热门城市引用。
- 当前 `城市.级别` 只有 `"省" | "市" | "区县"`，不支持 `"乡镇街道"` 或
  `"村社区"`。
- 当前 `创建行政区选择结果` 最多支持省 / 市 / 区县三层路径，超过三层会抛
  `RangeError`。
- 行政区划数据会变化，实施时必须固定数据来源、版本日期和更新脚本，而不是手工维护大数组。
- 官方口径：
  - 2025 年行政区划代码管理办法明确县级及以上代码由民政部确定，乡级代码由省级民政部门确定；民政部每年在国家地名信息库发布一次全国代码信息，省级民政部门每半年发布一次本地区乡级代码信息。
  - 省级、地级、县级行政区划代码采用六位数字码；乡级行政区划代码采用九位数字码，前三段继承上级县级代码，后三位表示街道、镇、乡等乡级建制。
  - 国家统计局城乡划分工作以村 / 居委会等村级单位为对象，统计用区划代码和城乡分类代码属于统计口径，不等同于普通行政区划产品数据。
- 用户已确认数据来源策略：官方公开源优先；如果官方源无法稳定批量获取，允许使用第三方整理库作为备选种子。
- 用户已确认全国范围包含港澳台。
- 用户已确认港澳台允许采用可变深度路径和地区专属层级名称，不强行补齐为大陆四级。

## Requirements

- R1. 数据层升级为全国行政区划数据；中国大陆至少覆盖省 / 自治区 / 直辖市、地级市 / 州 / 盟、区 / 县 / 县级市、乡镇 / 街道四级。
- R2. 数据来源必须可追溯，记录来源 URL、抓取时间、数据版本 / 年份、转换脚本版本和生成摘要。
- R3. 不再把完整大数据集手写在 `packages/data/src/index.ts`；应生成结构化数据文件或压缩常量，并保留可复现生成流程。
- R4. `packages/core` 的行政区类型、路径 helper 和搜索逻辑要支持新增层级，同时保持现有三层用法兼容。
- R5. `packages/data` 要提供全国数据导出、热门城市、按层级查询、按父级查询、按编码查询，以及完整校验。
- R6. `packages/taro` 和 demo 要能展示四级选择路径；如果保留三层 API，需要明确兼容行为。
- R7. 校验要覆盖编码唯一、父级完整、层级合法、名称非空、拼音 / 首字母、直辖市 / 省直辖县级市 / 无区县城市等特殊结构。
- R8. 文档要说明数据范围、来源、版本、更新命令、已知限制和是否包含港澳台 / 村社区。
- R9. 全仓库质量门禁继续使用 pnpm fallback，并要求 `lint`、`typecheck`、`format:check`、`test`、`validate:data` 全部通过。
- R10. 第一版明确不包含村 / 社区 / 居委会第五级数据；未来如果加入第五级，必须另开任务评估分片、懒加载、包体积和统计口径。
- R11. 第三方整理库只能作为官方源不可稳定批量获取时的备选；使用时必须记录库名、版本 / commit、许可证、获取时间，并通过官方编码规则、层级数量摘要和抽样校验兜底。
- R12. 第一版包含港澳台；港澳台数据必须标注来源和特殊层级口径，不能伪装成大陆四级行政区划。
- R13. 港澳台允许采用可变深度路径和地区专属层级名称；消费者必须能通过 `编码路径` / `名称路径` 展示完整路径，不能依赖固定四层字段。

## Notes

- 初版完整库包含中国大陆四级行政区划，以及港澳台数据。
- 村 / 社区 / 居委会属于更大规模、更强统计口径的数据，超过普通城市选择器的首屏和 bundle 预算，本任务不纳入。
- 数据来源采用官方优先、第三方备选；第三方数据不能绕过来源记录和校验要求。
- 港澳台行政层级、编码和地名口径不完全等同大陆四级，因此采用可变深度路径和地区专属层级名称。
- 本任务是复杂任务；开始实施前需要补齐 `design.md` 和 `implement.md`，并由用户确认规划。
